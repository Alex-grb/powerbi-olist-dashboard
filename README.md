# Дашборд Olist в Power BI

Интерактивный аналитический дашборд для бразильского маркетплейса Olist на основе PostgreSQL-базы (7 таблиц, 100 000+ заказов). Показывает ключевые метрики продукта: выручку, заказы, средний чек, доставку, географию, категории и способы оплаты.

## Что сделано
* Загружены данные из PostgreSQL в Power BI (через Power Query).
* Построена модель данных: таблица фактов `Olist_Data` связана с таблицей `Календарь` (DAX-календарь с полями Год, Месяц, ГодМесяц).
* Написаны меры на DAX: `Выручка`, `Кол-во заказов`, `Средний чек`, `Средний срок доставки`, `Выручка ПМ`, `Прирост MoM %`, `Выручка YTD`.
* Реализовано 5 страниц дашборда: общая выручка, категории, география, оплата, продавцы и доставка.
* Настроены срезы для фильтрации по периодам.

## Ключевые показатели (Total)
* **Выручка:** 13,81 млн
* **Количество заказов:** 115 тыс.
* **Средний чек:** 120,08
* **Средний срок доставки:** 12,02 дней

## Ключевые выводы по страницам

### 1. Общая динамика
Выручка и количество заказов растут синхронно. Сезонные спады не выражены. Единственный заметный спад — декабрь 2017 после пика в октябре–ноябре. Накопленная выручка по годам показывает устойчивый рост. Прирост MoM экстремален только в первые месяцы из-за эффекта низкой базы.

### 2. Категории товаров
Топ категорий по выручке не полностью совпадает с топом по заказам. Часть категорий зарабатывает за счёт объёма (например, `cama_mesa_banho`), а часть — за счёт более высокого среднего чека (например, `beleza_saude`).

### 3. География
Выручка сильно сконцентрирована в штате **Сан-Паулу (SP)** — около 7,4 млн выручки и 15 тыс. заказов. Следом идёт Рио-де-Жанейро (RJ) с 2,6 млн выручки и 6,6 тыс. заказов. Остальные штаты показывают плавное убывание. Основной рынок — юго-восток Бразилии.

### 4. Способы оплаты
Кредитная карта доминирует: **73,8%** заказов (85 тыс.), принося **10,6 млн** выручки. На втором месте boleto (22 тыс. заказов, 2,3 млн выручки). Средний чек почти одинаков у всех способов оплаты (около 120), то есть способ оплаты не влияет на размер чека.

### 5. Продавцы и доставка
Больше всего выручки приносит штат Сан-Паулу. Существенных отклонений по скорости доставки между топ-штатами нет. Отдельный выброс — штат Амазонас (47 дней доставки), но из-за малой доли выручки он не требует срочных мер.
